Значок — это статус, не тип. Всего четыре:

🔴 сломалось — нужно смотреть
🚨 инцидент — горит прямо сейчас
✅ прошло успешно (resolved — красноту разобрал дневной разборщик)
ℹ️ к сведению, действий не нужно

Строение сообщения, одно на все типы:

#тип #экземпляр
значок Type: action — имя, и оно ссылка, если есть куда; у PR и задачи — «PR (Merged) #414 · заголовок», номер и есть ссылка
скобка у слова типа говорит одним словом, чем кончилось, и стоит там, где исходов больше одного: Deploy (OK), CI (Fail), Job (Off), Job (Silent), Issue (Assigned), PR (Approved)
у инцидента состояния два не бывает, поэтому скобки нет: «🚨 Incident: The vault needs repair». Отдельного вида «сессия» больше нет — это инцидент: «🚨 Incident: Claude session is burning the limit»
у отчёта исхода нет, и скобку занимает день: «Report (2026-08-23 / 2026-08-22): Analytics»
у джоба строкой «Via: Mac» стоит, где он крутился (Mac, VPS, Actions) — первой строкой под второй; длительность прогона идёт строкой «Took: 4m 12s»
строки про людей (Author, Assignee, Reviewer) печатаются всегда, владелец в том числе; строки Actor нет — на пуше это автор коммита, по расписанию всегда владелец

Field: значение
цитата — только чужой текст дословно (тело коммита, тело задачи)

Group Name
#N (overdue): заголовок

Check: команда / Log: путь ← что нельзя сделать ссылкой (03.09.2026: ссылки лежат на именах во второй строке и на хеше коммита, отдельной строки Source нет)

Ярлык поля — жирный, с большой буквы, значение обычным текстом.
Заголовок группы — курсив и подчёркивание, без жирности, без двоеточия.
Тег наверху = машинный ключ, по которому разборщик сверяет 🔴 с починкой —
подчёркивание, не дефис (дефис рвёт тег Телеграма на середине).

Весь машинный текст — английский. Русским остаётся только цитируемое
человеческое содержимое — тексты коммитов, названия задач.
