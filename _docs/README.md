# notify простыми словами

Пакет `@mikitasazan/notify` шлёт в Telegram карточки одного вида: форум на
проект, вкладка Ops для роботов, вкладка Dev для людей. Свободный текст
отправить нельзя — только типизированное событие.

Канон формы карточки — [`product/CARD_FORMAT.md`](product/CARD_FORMAT.md).
Как читать значки человеку — [`guides/legend.md`](guides/legend.md). Как
устроены модули — [`architecture.md`](architecture.md). Почему форум на
проект, а не общая тема — [`DECISIONS.md`](DECISIONS.md).

Потребительский README (установка, CLI, Actions) остаётся в корне пакета.
